# Установка Silent VPN на OpenWrt

OpenWrt **23.05+** (opkg на 23/24, apk на 25+). aarch64, arm, mipsel, x86_64. Панель: `http://<LAN-IP>.silent.vpn`

## На роутере

В LuCI OpenWrt 23.05 нет пункта «Терминал» (он появляется только если установлен `luci-app-ttyd`). Команду вставляют по SSH с компьютера, уже в сессии роутера:

```sh
ssh root@192.168.1.1
```

Вместо `192.168.1.1` — IP админки. Логин `root`, пароль как у веб-интерфейса.

Если на OpenWrt нет интернета, его можно взять у другого роутера. Сначала смените LAN OpenWrt на `192.168.2.1` (**Сеть → Интерфейсы → lan**), иначе часто конфликт с домашним `192.168.1.1`. Дальше SSH: `ssh root@192.168.2.1`.

- Кабелем: LAN рабочего роутера → WAN OpenWrt (обычно синий порт). Не подключайте второй кабель в LAN рабочего роутера.
- По Wi‑Fi: сначала выключите свою точку доступа OpenWrt на этом радио (**Сеть → Беспроводная связь**). Затем **Сканировать** → ваша сеть → Присоединиться. Интерфейс `wwan`, DHCP-клиент, зона `wan` (не `lan`). ПК оставьте кабелем в LAN OpenWrt.

Если на рабочем роутере OpenWrt появляется и сразу пропадает — обычно ещё включена своя Wi‑Fi OpenWrt или кабель воткнут в LAN, а не в WAN.

Если ПК сидит на Wi‑Fi домашнего роутера, а кабель только с ПК на OpenWrt — этот кабель в **LAN OpenWrt** (иначе с ПК не зайти). Интернет OpenWrt тогда берёт сам по Wi‑Fi-клиенту к домашнему роутеру, не через кабель с ПК.

На overlay нужно около 25 МБ свободно (`df -h`, строка overlay). Диск около 8 МБ пакет не вмещает. Архив целиком не распаковывать: на маленькой памяти роутер зависает. Скрипт `openwrt-install.sh` на Pages сейчас не опубликован. Рабочая установка — один блок в SSH на странице «Роутер» локального лендинга: архив, только файл своего процессора, перевод строк, имя `IP.silent.vpn`, служба.

Вход: с компьютера **по кабелю LAN** (не с Wi‑Fi), VPN на компьютере выключен. Адрес `http://192.168.1.1.silent.vpn`. Если в меню прочерки и просит подписку — в опубликованном пакете заголовок входа режется по пробелу и аккаунт не читается. Блок «починить вход» на той же странице, затем войти ещё раз. Админ видит бессрочный доступ. Удаление: `sh /usr/sbin/silent-vpn-uninstall`.

## Сборка пакета (на компьютере)

```powershell
python scripts/build_wdtt.py
python scripts/build_release.py
```

`dist/silent-vpn-openwrt-1.0.165.tar.gz` — его кладут на `https://silentvpn3.github.io/silent-vpn-openwrt.tgz`. Скрипт `remote-install.sh` = `landing/openwrt-install.sh`. Удаление: `uninstall.sh` = `landing/openwrt-uninstall.sh`.

## Удалить

```sh
sh /usr/sbin/silent-vpn-uninstall
```
