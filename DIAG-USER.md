# Диагностика Silent VPN на OpenWrt (для пользователя)

Скрипт **только читает** состояние роутера и пишет отчёт в файл.
Он **не** включает/выключает VPN, **не** меняет настройки и **не** трогает пароли.

Нужен, когда:
- с «белыми списками» / исключениями VPN работает, без них — нет;
- работает только Telegram, остальное «глухо»;
- русский сегмент не открывается;
- тумблер «Отключить» сам снова включает VPN;
- после установки/перезагрузки не открывается панель.

## Как запустить (SSH)

1. С компьютера в той же сети, что и роутер (у Cudy часто `192.168.10.1`, у других — `192.168.1.1`):

```sh
ssh root@192.168.10.1
```

2. Панель должна открываться и по Wi‑Fi, и по кабелю. Если `….silent.vpn` не открывается — сначала голый IP:

```text
http://192.168.10.1
```

(подставьте свой LAN IP). Если на телефоне/ПК включён свой Silent VPN — отключите его для входа в панель роутера (иначе запрос уходит в туннель клиента, а не в локальную сеть).

3. На роутере положите скрипт **с тем же именем** `diag_router.sh` (файл из чата поддержки) и запустите:

```sh
sh /tmp/diag_router.sh
```

Как залить файл на роутер с ПК (в той же Wi‑Fi/LAN):

```sh
scp diag_router.sh root@192.168.10.1:/tmp/diag_router.sh
ssh root@192.168.10.1 "sh /tmp/diag_router.sh"
```

Если удобнее без scp — откройте `diag_router.sh` в блокноте, скопируйте весь текст и на роутере:

```sh
cat > /tmp/diag_router.sh <<'EOF'
…весь текст скрипта…
EOF
sh /tmp/diag_router.sh
```

3. В конце скрипт напишет путь вида `/tmp/silent-vpn-diag-….txt`.

4. **Пока VPN в «сломанном» состоянии** (тумблер включён, сайты не открываются) — не выключайте тумблер и не перезагружайте роутер, пока не сохраните отчёт.

5. Скиньте файл в поддержку. С ПК:

```sh
scp root@192.168.10.1:/tmp/silent-vpn-diag-*.txt .
```

Или в SSH:

```sh
cat /tmp/silent-vpn-diag-*.txt
```

и перешлите текст целиком.

## Что написать вместе с отчётом

- Модель роутера и версия OpenWrt (например Cudy TR3000, 25.12.4).
- Включены ли «Исключения → Российские сервисы мимо VPN» в момент сбоя.
- Что открывается / не открывается: Telegram, ya.ru, google.com, YouTube.
- Воспроизводится ли: «нажал Отключить — снова включился».
- Точное время сбоя (МСК).

В отчёте нет пароля аккаунта и приватных ключей WireGuard.
