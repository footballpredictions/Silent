# Silent VPN для OpenWrt

Свой клиент для роутера: агент совместим с тем же backend, что PC / Android / iOS, веб-панель в стиле клиентов, вход по `{lan-ip}.silent.vpn`.

Код **не** форк LuCI, AmneziaWG и Passwall. Заметки по чужим проектам: [RESEARCH.md](RESEARCH.md). Установка: [INSTALL.md](INSTALL.md).

## Установка на роутер

OpenWrt 23.05+. aarch64, ARMv7, mipsel (little-endian), x86_64. [Инструкция](INSTALL.md).

В SSH-сессии роутера проверьте свободное место:

```sh
df -h /tmp /usr; free -m
```

Установщик проверит RAM и место, скачает пакет только для вашего процессора
и удалит свои временные файлы. Для сборки: `python scripts/build_release.py` —
одной командой четыре архива в `dist/`.

Установите (роутеру нужен интернет):

```sh
wget -O /tmp/sv.sh https://silentvpn3.github.io/openwrt-install.sh && sh /tmp/sv.sh
```

Подключитесь к локальной сети роутера по Wi-Fi или кабелю. Откройте
`http://<LAN-IP>.silent.vpn` (панель напрямую: `http://<LAN-IP>/silent-vpn/`). Доступ к панели — только из LAN.
Войдите, включите
«Российские сервисы мимо VPN» в «Исключениях», затем включите VPN.

Удаление:

```sh
sh /usr/sbin/silent-vpn-uninstall
```

После установки версии с поддержкой OTA новые версии проверяются при открытии
панели и каждые 15 минут. Кнопка «Доступно обновление» появляется внизу главного
экрана вместо статуса подписки, как в PC. Пакет выбирается по CPU, проверяется SHA256,
сохраняются аккаунт и настройки. Перед заменой файлов создаётся временная
резервная копия, при ошибке установки она восстанавливается. Загрузка и копия
удаляются после завершения; VPN переподключается, если был включён.
Пакет сначала скачивается и проверяется при работающем VPN. Затем VPN временно
останавливается, освобождая RAM для распаковки и резервной копии.

## Локальный просмотр веба

На Windows из этой папки:

```powershell
python scripts/preview.py
```

Откроется `http://127.0.0.1:7788/` — макет телефона и адресная строка `http://192.168.1.1.silent.vpn`.

Другой LAN для проверки строки:

```powershell
$env:SILENT_PREVIEW_LAN="10.0.0.1"
python scripts/preview.py
```

Вход в preview: любой email и пароль от 8 символов. Тема тянется с живого `GET /api/vpn/theme` (если Улей отвечает).

Тесты:

```powershell
python -m unittest discover -s tests -v
```

## Состав

| Путь | Зачем |
|------|--------|
| `web/` | Панель (HTML/CSS/JS), server-driven theme |
| `files/` | То, что попадает на роутер (init, CGI, агент) |
| `lib/` | Hostname и палитра — preview + тесты |
| `scripts/preview.py` | Локальный сервер панели |
| `Makefile` | Пакет OpenWrt `silent-vpn` |
| `install.sh` | Копирование на живой роутер без SDK |

Интерфейс агента один: `silent-vpn-ctl`. Веб ходит только в локальный CGI.

«Российские сервисы мимо VPN» направляет через WAN домены `.ru`, `.su`, `.рф`
и отдельные домены российских сервисов/CDN в других зонах. Список DNS-суффиксов
настраивается в админке Улья → «Доп. настройки». Два списка: «Мимо VPN» и
«Всегда через VPN» (приоритетный). Существующие MAX, маркетплейсы, Школково,
Flashscore и исключение GDZ перенесены в серверные настройки.

Роутер получает `/api/vpn/routing-policy` при включении и затем раз в пять минут.
При недоступном API перебирает публичные прокси сот до первого корректного ответа.
Последняя рабочая копия хранится в `/etc/silent-vpn/routing-policy.json`;
пакетные `ru-direct.domains` / `ru-vpn.domains` остаются стартовым fallback.
Отдельный `silent-vpn-policy` восстанавливает nft-наборы и маршрут WAN раз в минуту,
не перезапуская VPN. Снимки изученных IP находятся только в RAM; flash меняется
при обновлении серверного списка. DNS перезапускается при переключении рубильника
или изменении списка, а не на каждом фоновом проходе.
