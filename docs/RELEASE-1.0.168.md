## Standards

PC native pins согласованы с бинарниками. В OpenWrt выявлены и устранены два дефекта: повышение приоритета неработающего HTTPS-запроса по IP без доменного Host и CRLF shell-скрипты в архиве из Windows checkout. Ранее сохранённый API-priority/timeout diff скопирован вне Git, затем возвращён проверенный cell-first порядок. Работающий туннель по-прежнему использует только свой шлюз. Добавлены сценарии реального shell request loop; они ловят прежний неверный приоритет. Регресс CRLF сначала упал, после изменения упаковщика прошёл; нормализация не меняет исходные файлы и ELF. Повторное независимое ревью четырёх OpenWrt-файлов новых проблем не обнаружило.

TECHNOLOGY.md отражает порядок17.09, MEMORY_BANK — новый общий замысел27.09. Для OpenWrt возврат обоснован его фактическим wget-транспортом: в отличие от Android/PC он не переопределяет Host для IP. nginx default HTTPS возвращает444, поэтому IP первым добавлял неудачную попытку до8с перед сотами.

## Выпуск пользователем

1. Создать Release `v1.0.168` в `silentvpn3/silentvpn3.github.io`, загрузить четыре файла из `releases/github-release-v1.0.168/` с указанными именами, опубликовать Release и убедиться, что файлы скачиваются.
2. В тот же GitHub Pages-репозиторий поместить четыре файла из `releases/github-pages-1.0.168/`: `silent-vpn-openwrt.tgz`, `openwrt-install.sh`, `openwrt-uninstall.sh`, `releases.json`. Манифест публиковать после доступности Release assets, чтобы клиенты не получили ссылки на ещё отсутствующие файлы.
3. После Pages deployment проверить `https://silentvpn3.github.io/releases.json`: pc/android/linux1.0.168, размеры и URL совпадают с таблицей. Проверить install/uninstall URL на200 и новую версию архива; OpenWrt без встроенного OTA обновляется установочным скриптом вручную.
4. После Mac-сборки отдельно добавить рабочие DMG и соответствующие `mac.arches.x64/arm64` в манифест. До этого не объявлять Mac/iOS готовыми.

Итог ревью: Standards — два дефекта устранены, нерешённых находок в изменениях нет. Spec — один публикационный пробел, подготовлены файлы для его закрытия при самостоятельном выпуске.
