# Android: тестовая сборка только UDP, 2 ноября 2026

По результату владельца предыдущая сборка в UDP дала около 100 Мбит/с. По его просьбе выбор UDP/TCP/TLS удалён: приложение всегда использует UDP, интерфейс выбора сервера возвращён к прежнему виду. Это наблюдение владельца, причина роста скорости отдельно не установлена.

Сохранены UDP-часть проверенной сборки: выбор только UDP-адресов TURN с учётом URI провайдера, разрешение адресов через `resolveUDPAddrNoRoute`, прежние размеры сокетных буферов, остановка сокета вместе с контекстом. Диспетчер пакетов, chunk8, очереди, MTU, DTLS/WG и лимиты параллелизма не перенастраивались. Статистика возвращена к исходному виду: только «Активных: … | Трафик: … МБ» в логе и уведомлении. Расширенные UDP/RX/TX/dropTX/queueRX и их дополнительные счётчики удалены. Реализация TURN-over-TCP/TLS и CLI-переключатель удалены.

Число каналов сохраняется в прежних preferences и применяется также при запуске из кеша. Настройка доступна в существующем debug-разделе «Хеши» → «Сила каналов». Экспериментальная панель с выбором транспорта и отдельный экран предпросмотра удалены. Сохранённое ранее значение TCP/TLS больше нигде не читается и не влияет на подключение.

## Установка

APK: `releases/SilentVPN-udp-clean-1.0.171-20261102.apk`. Имя приложения «Silent VPN (UDP-тест)», package `com.silent.vpn.transporttest`, version `1.0.171-udp-20261102`.

Установить поверх предыдущей тестовой APK, без удаления приложения: package и debug-подпись сохранены, поэтому вход и настройки остаются. Основное приложение не заменяется. Одновременно Android допускает только один активный VPN.

## Сборка и проверка

Из `android` выполнить `./scripts/build_transport_lab.ps1` в PowerShell с JDK17, Android SDK/NDK и Go1.26.3. Внутреннее имя параметра Gradle `-PtransportLab=true` сохранено для изоляции private native libraries в `app/src/transportLab/jniLibs`. Скрипт строит четыре ABI, выполняет Android unit-тесты и собирает debug APK. Release с этим параметром запрещён; обычная release продолжает использовать прежние библиотеки из `src/main/jniLibs`.

`go test ./...` и `go vet ./...` проверяют native-код, включая реальный локальный UDP TURN allocation и обмен datagram в обе стороны через Android `mobileNet`. Полевую скорость проверяет владелец на своей сети. Сборка и временное размещение APK не перезапускают VPN и не заменяют OTA-релиз.
