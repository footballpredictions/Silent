# Отдельный приёмник уведомлений ЮMoney

Новый вход: `https://153-52-117-159.nip.io/api/payments/yumoney/notify`.
Старый `/api/payments/yumoney/notify` Улья и маршруты клиентов сохраняются.
Изменить URL HTTP-уведомлений нужно в настройках **каждого** используемого кошелька
ЮMoney. Перенастройка не требует обновления клиентов. В кабинете один URL на кошелёк,
поэтому старый обработчик остаётся доступным, но кошелёк отправляет на выбранный URL.

Приёмник проверяет HMAC-SHA256 (поддерживает исторический SHA-1), сохраняет
исходное тело в SQLite WAL с synchronous=FULL и только после commit отвечает 200.
Рабочий процесс отправляет неизменённое тело по HTTPS на Улей (443, затем 2083),
где снова проверяются подпись, сумма, label и уникальность операции.
Нет базы пользователей, VPN, административных токенов или ключей VPN.

При недоступном Улье уведомления остаются на диске и повторяются без ограничения
числа попыток с задержкой 2–300 секунд. Активация произойдёт после восстановления
Улья; этот сервер не заменяет API входа/конфигов и не может сам выдать подписку.
Просроченная платёжная заявка может принять подлинное позднее уведомление;
completed/failed и повторы не начисляют срок снова.

`/health` проверяет хранилище и показывает pending, возраст старейшего сообщения,
число попыток и последнюю доставку. Нулевой pending означает отсутствие очереди;
для контроля входа нужен тест в кабинете кошелька. Поддельное уведомление даёт 400,
ошибка сохранения/переполнение — 503, чтобы ЮMoney повторил запрос.

Сервис: `silent-payment-relay.service`, код `/opt/silent-payment-relay`, очередь
`/var/lib/silent-payment-relay/inbox.sqlite3`. Доставленные тела удаляются, хеши
остаются для защиты от повторов. Не удалять очередь или WAL при рестарте/обновлении.

Конфиг `/etc/silent-payment-relay/config.json`: владелец root, группа сервиса,
права 0640. Поля: database, notification_secrets (ключи **всех** кошельков),
upstreams (фиксированные HTTPS адреса notify). Секретов в репозитории нет.
При добавлении кошелька/смене notification secret нужно обновить конфиг и
перезапустить только этот отдельный сервис; ранее сохранённые сообщения остаются.

Nginx публикует только notify, health и ACME challenge; ограничения тела/скорости,
приложение слушает только 127.0.0.1:9180. HTTPS использует Let's Encrypt.
Продление сертификата: certbot.timer, deploy hook перезагружает nginx.
HTTP на новом адресе также принимает notify для совместимости; в ЮMoney выбрать HTTPS.

Проверки: `cd payment-relay && python3 test_relay.py`; дополнительно backend
`python -m unittest scripts.test_payment_unit scripts.test_prepaid_renewal_unit`.
Никаких реальных денежных операций в тестах. Live smoke использует неизвестный
label с test_notification=true, поэтому Улей отвечает unknown_label без начисления.
