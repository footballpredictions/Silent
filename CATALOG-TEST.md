# Изолированная проверка серверного каталога

Сборка: из `app/` выполнить `gradlew.bat assembleDebug -PwhitelistCatalogTest=true`.
Пакет `com.silent.vpn.catalogtest`, название «Silent VPN (каталог-тест)», версия 1.0.171.
Не заменяет release/debug, не копирует их аккаунты, настройки или исключения. OTA релизного APK в тестовом профиле отключено.
Обычный debug и любой release используют прежний серверный список, даже если release собирали с этим Gradle-параметром.

Тестовый профиль запрашивает `/api/vpn/routing-policy?profile=catalog-test` через существующий зашифрованный relay.
Точные имена из `direct_exact_domains` не распространяются на поддомены. `direct_domains` содержит только явные suffix-правила источника.
Исключения `vpn_domains` берутся из действующей общей политики и имеют приоритет. Дефолтный API и общий DIRECT не меняются.
Снимок для первого старта лежит в `app/src/catalogTest/assets/catalog-test-policy.json`; обычные сборки его не включают.
Профиль получает последующие обновления каталога без пересборки. При ошибке остаётся последний валидный список.

## Проверка на телефоне

1. Установить отдельный тестовый APK, войти в свой аккаунт. Авторизация не переносится из основного приложения.
2. Отключить VPN в основном приложении перед подключением тестового: Android допускает только один VPN одновременно.
3. Подключить тестовый VPN, включить «Российские сервисы мимо VPN» и дождаться «Список получен».
4. Экран исключений оставлен таким же, как в релизе: диагностические числа/revision и тестовые пояснения убраны по просьбе владельца. Профиль и число правил проверяются через API/автотесты, а не текст интерфейса.
5. Сравнить конкретные сайты с режимом ON/OFF, сохраняя VPN включённым. Записать оператор, сеть и адрес неработающего сайта.
6. Для возврата отключить тестовый VPN и подключить основной. Основной APK и его данные не удалять.

Наличие домена в исходниках сообщества НЕ подтверждает доступность при ограничениях конкретного оператора.
Без SIM-пробы сервер не может измерить её. MAX отдельно проверяет наличие Android VPN: один доменный DIRECT эту проверку не устраняет.
В тестовой сборке сохранённые исключения приложений продолжают действовать вместе с RU-режимом (включая сохранённый режим ЧС/БС). MAX `ru.oneme.app` автоматически исключается целиком при RU ON, даже если выбран для VPN в БС. После RU OFF остаётся только сохранённый ручной режим; списки не переписываются. Редактирование при RU ON по-прежнему заблокировано; ручные правила сайтов временно отключены. Bootstrap/оплатные overlay автоматическое исключение MAX не получают. В обычном debug/release поведение не менялось.

## Автотесты

`CatalogTestPolicyDeviceTest#isolatedProfileUsesTypedFallbackAndRejectsProductionCache` проверяет только данные изолированного пакета, не меняя VPN.
Опциональный `liveEncryptedRelayReturnsOnlyCatalogProfile` требует `-e catalogLiveRelay true` и уже работающий relay другого Silent-пакета на 127.0.0.1:18766.
Без него этот live-тест не проверяет доступность: instrumentation останавливает процесс целевого тестового приложения и поэтому не может использовать его собственный активный VPN.
