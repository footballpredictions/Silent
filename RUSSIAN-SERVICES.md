# Российские сервисы мимо VPN

Первый тумблер экрана исключений включает общий режим для приложений. По умолчанию выключен. Оба ручных списка сайтов и приложений, включая режимы ЧС/БС, сохраняются: при включении они недоступны и не участвуют в маршрутизации; выключение возвращает их прежнее состояние.

Политика берётся из публичного GET `/api/vpn/routing-policy`, с проверкой схемы, суффиксов, revision и размера. При ошибках используется последний корректный кеш или встроенный снимок 117 DIRECT / 1 VPN. VPN-правила выше DIRECT, включая общий IP. Служебная сеть 10.66.66.0/24 остаётся в туннеле. Bootstrap и временные API/payment overlay используют прежние правила.

Обработка системного DNS выбирает WAN-ответы для DIRECT и устанавливает соответствие до передачи ответа приложению. Остальные назначения остаются в VPN. Для DIRECT подавляются IPv6/HTTPS/SVCB-подсказки, чтобы приложение запросило поддерживаемую IPv4-запись. Собственный DoH/DoT и жёстко заданные IP приложения не дают доменные ответы для такой классификации и сохраняют обычный VPN-путь.

Обновление списка по stdin/ACK сохраняет WG/TUN; активный DIRECT-поток переживает истечение DNS TTL. Изменение самого пользовательского режима может заменить TUN для применения политики приложений. Ручное применение сериализовано с overlay. Фоновая загрузка привязана к процессу транспорта, поэтому изменение числа воркеров её не выключает.

Проверки 2026-10-16: 331 JVM; 18 native Go на x86/API28; 14 инструментальных проверок на отдельном эмуляторе. В них проверены обе сохранённые пары списков, bootstrap/overlay, подтверждение RU-обновления без замены native-процесса и предыдущие сценарии восстановления связи/энергопотребления. В первом общем прогоне один service fixture завершился таймаутом; без изменения кода восстановления прошли отдельный, парный и два полных повторных прогона. Настоящее перемещение между вышками в этой задаче не проверялось.

Собран debug 1.0.169 для четырёх ABI. Подпись v2 проверена; исходные native-файлы совпали с merged, а stripped-файлы — с содержимым APK. Release/OTA и сервер не изменялись.
