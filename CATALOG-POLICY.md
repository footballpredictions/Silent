# Объединённые исключения — 2026-10-28

Новые сборки при включённых российских сервисах запрашивают каталог вместе с ручными правилами (`profile=catalog-test`). Если каталог недоступен, сохранён прежний обычный профиль/кеш. Глобальная политика backend и старые клиенты не меняются. Источники: [контракт dnsmasq](https://thekelleys.org.uk/dnsmasq/docs/dnsmasq-man.html), backend whitelist_test_policy.py.

Точные имена, доменные правила и приоритет VPN обрабатываются общим Go-пакетом `keenetic/agent/routerpolicy`. OpenWrt использует DNS-адаптер из `keenetic/agent/cmd/router-dns`: dnsmasq сохраняет локальные имена/DHCP/кеш и пересылает внешний DNS локальному процессу UDP/TCP 127.0.0.1:15354. Его включение требует готового туннеля и проверенной политики; DNS переключается после сигнала готовности. При отключении режима, VPN или удалении собственная запись убирается и DNS восстанавливается. Процесс ограничен 64 запросами и GOMEMLIMIT=16MiB, журналы запросов не пишутся. Точные правила сохраняются без расширения на поддомены. IP-based routing сохраняет общее ограничение: один CDN-IP может обслуживать несколько имён, DoH/DoT обходят DNS роутера.

Прежний профиль: `uci set silent-vpn.main.routing_profile=standard`, `uci commit silent-vpn` и штатное переподключение клиента. Новый профиль: `catalog-test`. Без установленного адаптера не принимается каталог, требующий точных правил.

Сборка `python openwrt/scripts/build_release.py` требует sibling `pc/wdtt-go` и `keenetic/agent`. Каждый из четырёх CPU-пакетов содержит только свою пару transport/DNS ELF. Роутер и VPN-службы серверов во время сборки не трогались.

Диагностика iQOO/Android 17 при VPN на роутере: `scripts/diagnose_wifi_client.py` — только чтение через уже разрешённый ADB. Не устанавливает APK, не переподключает Wi-Fi и не меняет настройки. В 20 замерах сбой не воспроизведён; исправление случайного обрыва не подтверждено. Для следующего случая нужен снимок до переподключения Wi-Fi. USB и тестовые HTTP-запросы могут влиять на условия простоя, поэтому этот прогон не доказывает отсутствие проблемы.
